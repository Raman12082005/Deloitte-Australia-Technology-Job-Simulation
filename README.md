# Deloitte-Australia-Technology-Job-Simulation

This repository contains my completed solution for the Deloitte Australia Technology Job Simulation hosted on Forage. The simulation provided hands-on experience in solving real-world software engineering and consulting tasks using Python and software development best practices.

# Project Overview:-
The simulation consisted of two practical tasks :

# Task 1: Data Transformation Using Python :
Developed a Python program to reconcile two different IoT telemetry data formats into a unified JSON structure. The solution involved reading JSON files, transforming nested data, converting ISO 8601 timestamps into Unix milliseconds, and validating the output using Python's unittest framework.

# Task 2: Software Development Proposal :
Prepared a professional software development proposal for a real-time manufacturing dashboard. The proposal included project objectives, functional scope, development estimates, project timeline, and post-deployment support based on the client's business requirements.
